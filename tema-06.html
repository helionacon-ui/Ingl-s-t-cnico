Especialidad y comunicación · Tema 6

Automation & control

Especialidad y comunicaciónEspecialidad

Desde cero

Objetivo: manejar la terminología de control automático e instalaciones industriales, y las estructuras condicionales y de causa-efecto que describen el comportamiento de un sistema.

  • El vocabulario de control es casi transparente (controller, sensor, actuator, feedback), pero las estructuras que lo rodean no: condicionales, causa-efecto y comparación de prestaciones.
  • Las condicionales son la columna vertebral de cualquier descripción de automatismo: tipo cero para leyes generales («if the temperature rises, the valve opens») y primera para situaciones concretas («if the sensor fails, the system will shut down»).
  • La cadena causa-efecto se encadena con this causes…, which results in…, leading to…, hence….
  • Cuidado con tres falsos amigos frecuentes en este campo: actual (real, no «actual»), eventually (finalmente) y to control (que sí significa controlar, pero control como sustantivo es «mando» o «regulación», no «control» de inspección, que es check o inspection).
  • En instalaciones aparecen muchos phrasal verbs: switch on/off, start up, shut down, back up, set up, trip.

Explicación ampliada

Condicionales de tipo 0, 1 y 2

Los tres que más se usan en automatismos: tipo 0 (ley general, siempre cierto): If + presente, presente → «If the pressure exceeds 5 bar, the valve opens». Tipo 1 (caso real futuro): If + presente, will + infinitivo → «If the pump fails, the system will switch to the standby unit». Tipo 2 (hipotético): If + pasado, would + infinitivo → «If the gain were higher, the response would be faster» (en tipo 2 con to be se usa were). No se pone will después de if.

Describir un lazo de control

Nombra los elementos con su función: el sensor mide la process variable; el controller compara con el setpoint y calcula la acción; el actuator actúa sobre la manipulated variable; la disturbance perturba el proceso. Para la respuesta: rise time, settling time, overshoot, steady-state error, damping. Estructura de secuencia: condición → acción → resultado, una frase por paso, y nombrando siempre el elemento («the solenoid valve opens», no «it opens»).

Vocabulario y expresiones

  • Elementos: sensor, transmitter, controller, actuator, final control element, setpoint, process variable, manipulated variable, disturbance.
  • Lazo: open-loop, closed-loop, feedback, feedforward, gain, proportional / integral / derivative action, tuning.
  • Respuesta: rise time, settling time, overshoot, steady-state error, damping, stability, oscillation.
  • Industria: PLC, SCADA, HMI, fieldbus, ladder diagram, relay, contactor, limit switch, emergency stop, interlock.
  • Condicionales: tipo 0 «If the pressure exceeds 5 bar, the valve opens» · tipo 1 «If the pump fails, the system will switch to the standby unit» · tipo 2 «If the gain were higher, the response would be faster».
  • Causa-efecto: this causes / leads to / results in · as a result · consequently · therefore · due to · owing to.
  • Fallos y mantenimiento: to fail, to trip, to jam, to leak, to overheat, downtime, troubleshooting, preventive maintenance, spare part.

Cómo abordarlo

  1. Para describir un automatismo, usa la secuencia condición → acción → resultado, una frase por paso.
  2. Elige el tipo de condicional según sea una ley general (tipo 0, presente-presente) o un caso futuro (tipo 1, presente-will).
  3. Nombra siempre el elemento del lazo que actúa: no «it opens», sino «the solenoid valve opens».
  4. Al comparar prestaciones, usa comparativos con than y cuantificadores: «significantly faster than», «slightly more accurate».
  5. Desarrolla las siglas la primera vez que aparezcan.

Errores típicos

  • «If» + will en la subordinada: «if the pump will fail» ⇒ «if the pump fails».
  • Usar actual por «actual»: es current; actual value significa «valor real».
  • Traducir «realimentación» como retroalimentation: es feedback.
  • Decir security cuando se habla de seguridad frente a accidentes: eso es safety; security es seguridad frente a intrusos.
  • Usar sensible por «sensible»: es sensitive.
  • Olvidar la -s de tercera persona en el presente de las condicionales de tipo 0.

Tarea tipo

Enunciado

Explica el funcionamiento de un automatismo en 6-8 frases: un depósito con control de nivel por dos interruptores (alto y bajo), una bomba, una alarma y una parada de emergencia. Usa condicionales y conectores de causa-efecto.

✓Ver solución paso a paso

The tank level is monitored by two float switches, one at the low level and one at the high level. If the level falls below the low switch, the PLC starts the filling pump. As soon as the liquid reaches the high switch, the pump is switched off, so that the tank cannot overflow. Should both switches fail, the level would keep rising, which would result in a spill; for this reason an independent overflow sensor is fitted as a backup. If that sensor is triggered, an audible alarm will sound and the inlet valve will close automatically. In the event of an emergency, the operator can press the emergency stop button, which removes power from the pump and the valve. Consequently, the plant reverts to a safe state even if the control system is not working.

Las estructuras que hay que saber colocar:

  1. Condicional tipo 0 para la lógica normal: «If the level falls…, the PLC starts…» (presente + presente).
  2. Condicional tipo 1 para el caso futuro concreto: «If that sensor is triggered, an alarm will sound».
  3. Should + sujeto como inversión formal equivalente a «if… should»: «Should both switches fail, …». Da nivel al texto.
  4. As soon as para la inmediatez y so that para el propósito.
  5. In the event of + sustantivo, la fórmula de los manuales de seguridad.
  6. Which explicativo referido a toda la frase anterior y even if para la concesión.

Observa que no aparece ni un solo «and then»: en inglés técnico las relaciones lógicas se marcan con conectores precisos, y eso es exactamente lo que diferencia un aprobado de un notable en el portafolio.

Ejercicios resueltos

Intenta cada uno antes de desplegar la solución.

Ejercicio 1 · Tipo de condicional

Identifica el tipo y corrige si hace falta: (a) If the temperature will rise, the fan starts. (b) If the sensor fails, the PLC will stop the line. (c) If I was you, I would increase the gain.

✓Ver solución paso a paso
  • (a) Incorrecta: tras if no va will. Correcta: «If the temperature rises, the fan starts» (tipo 0).
  • (b) Correcta, tipo 1.
  • (c) Tipo 2; en estilo formal: «If I were you, I would increase the gain».

Ejercicio 2 · Describe un automatismo

Describe con condición → acción → resultado una bomba de achique con interruptor de nivel.

✓Ver solución paso a paso

If the water level reaches the upper float switch, the controller starts the pump. As a result, the level falls. When the level drops below the lower float switch, the pump stops. If the pump fails, an alarm will sound and the operator will be alerted.

Ejercicio 3 · Interpreta la respuesta

Explica en inglés: «overshoot of 20 %, settling time 4 s, steady-state error 0».

✓Ver solución paso a paso

The response exceeds the setpoint by 20 % before settling. It takes four seconds to stay within the tolerance band, and finally there is no steady-state error: the process variable reaches the setpoint exactly.

Autoevaluación

Responde antes de desplegar.

1¿Qué condicional se usa para la lógica de un automatismo?

La de tipo 0 (presente + presente) para leyes generales: «If the pressure exceeds 5 bar, the relief valve opens». La de tipo 1 (presente + will) para un caso futuro concreto.

2¿Por qué «if the pump will fail» es incorrecto?

Porque en la subordinada condicional no se usa will: «if the pump fails, the system will stop». El futuro va sólo en la principal.

3¿Qué diferencia hay entre safety y security?

Safety es la seguridad frente a accidentes (lo que se trata en una planta); security es la protección frente a intrusos o ciberataques.

4¿Qué significa actual value?

El valor real medido, frente al setpoint o valor de consigna. Actual nunca significa «actual» en el sentido de «de ahora».

5¿Cómo se dice «parada de emergencia» y «enclavamiento»?

Emergency stop (coloquialmente e-stop) e interlock. Y «la protección ha saltado» es «the breaker has tripped».
